# Frontend

The frontend is a React + TypeScript app built with Vite.

## Key Responsibilities

- landing page and app shell
- quick workout logging UI
- history, analytics, and profile views
- OAuth screens for MCP login and consent
- client-side state and API integration

## Important Locations

- `src/App.tsx`: top-level routing and entry views
- `src/components/views/`: page-level screens
- `src/components/quick-log/`: workout logging interface
- `src/components/history/`: session history UI
- `src/components/oauth/`: auth-related screens
- `src/components/ui/`: reusable UI primitives
- `src/lib/`: types, utilities, state, and API helpers
